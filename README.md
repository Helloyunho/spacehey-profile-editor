# SpaceHey profile editor
### A live editor for SpaceHey profiles!

This is a simple web-tool for editing your [SpaceHey profiles](https://spacehey.com/ "SpaceHey homepage") without having to save and refresh your profile every 5 seconds!
Instead you get a live updating preview that should be *(I hope 99%)* accurate to the real thing!

Comes with options to edit/preview as many of the options you aer able to edit on SpaceHey, allowing for the best preview of your actual profile.

This project is not affiliated with SpaceHey, please report any issues to Skyla and not SpaceHey!
